# Security policy

Do not report vulnerabilities, leaked credentials, private audit records, or
production-cluster details in a public issue.

Before this project is published, security reports should be shared privately
with the project owner. After GitHub publication, enable and use GitHub private
vulnerability reporting.

For vulnerabilities in OpenSearch itself or the OpenSearch Security plugin,
follow the OpenSearch Project's security-reporting process rather than
disclosing the issue in this repository.

## Supported versions

Only the latest release is supported during the pre-1.0 development phase.
